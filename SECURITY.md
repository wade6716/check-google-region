# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability (especially involving credentials handling, proxy bypass, or unexpected network exposure), please **DO NOT** create a public GitHub issue.

Instead, please send an email to `wade67168@gmail.com` with:
- Description of the issue
- Steps to reproduce
- Potential impact

We will evaluate and respond within 48 hours.
